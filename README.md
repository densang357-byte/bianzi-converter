# 辨字

結合詞界、詞性、句法與局部語義的簡繁轉換工具。支援文字、TXT、EPUB，以及默認、OpenCC、臺灣、香港、港臺舊字形、古籍、調和和《學生字典》方案。

## 各標準字形

[九種方案的字形對照與字表下載](standards/README.md)：列出綫／線、衞／衛、朶／朵、牀／床、羣／群、峯／峰等差異，提供各方案的 JSON、TSV 及完整單字差異表。

## 伴生字怎樣參與選字

伴生字是能幫助判斷詞義的語義線索。工具把它們整理成獨立語義節點，再檢查它們和歧義字之間的局部句法關係。

例如，「背」的受事若是需要負重搬運的容器或物件，可支持「揹」；「鍊」須核對實物鏈條、材質或拴繫關係；「丑」須核對它在干支中的實際角色。線索可以隔開幾個詞，無須緊貼歧義字，但必須有符合規則的結構關係。僅在同一句出現、字面相鄰或共現頻次高，都不足以直接決定用字。未能確認的關聯列入待核風險。

## 詞性轉換怎樣運作

快速模式使用 **HanLP**，慢速模式使用 **LTP**。兩者均實際分詞、標註詞性並分析句法，再結合詞庫及局部規則選字。詞庫模式屬兼容選項，不等同快速模式。

詞性是判斷依據之一：同一個 `v` 仍可能有不同詞義；`n`、`nh`、`ni`、`ns`、`nz`、`nl`、`nd`、`nt` 分開處理，數詞 `m` 和量詞 `q` 也不合併。模型可能切錯詞或判錯實體，因此分析層的修正與建議另存，保留原生標註。

以下為用字原則示例，實際判斷仍須看語境：

| 字組 | 區分原則 |
| --- | --- |
| 才／纔 | 才能、才性、名物等用「才」；僅僅、方始、條件及強調副詞等用「纔」。 |
| 制／製 | 控制、限制、制定等用「制」；製作義用「製」。動詞未決默認「製」，並列風險；普通名詞默認「制」。 |
| 斗／鬥 | 器物、容量、星名等保留「斗」；競鬥事件及實際鬥爭動詞用「鬥」。 |
| 占／佔 | 占卜、觀兆、口占用「占」；據有、佔領及份額義用「佔」。未決默認「佔」，並列風險。 |
| 鏟／剷 | 工具義用「鏟」，剷除等動作義用「剷」。 |
| 計劃／計畫 | 依詞性與局部結構區分動作和名詞義。 |
| 諮／咨 | 如「諮詢」「咨文」，依詞義區分。 |

## 轉換原則

- **先辨詞界，再辨詞義。** 整詞詞庫只收詞彙義；跨詞界字串及可組合片段放入獨立風險庫，不能反向污染分詞或自動選字。
- **字形偏好與詞義分化分開。** 默認方案取「綫、衞、裡」，一般統一用「考」；「瞭解」屬字形偏好。各標準保留自己的字形設定。
- **保留指定原字。** 原文「象」保留；「哩、覆、榦、澂」不參與雙向自動轉換。保留原字的政策從有效底層表生效。
- **不把推定當成確認。** 專名、詞界、詞性及未決兜底分別列風險；模型標籤和規則命中都不是人工金標。
- **每次轉換留存診斷。** 文字、批次與直接 API 呼叫均記錄；每次使用獨立 runId，同一文件分批可共用，以來源雜湊、設定及版本核對續跑。
- **文件輸出另存。** 保留來源結構和原文註；豎排按需套用，不隨簡繁轉換自動啟用。

診斷保存在本機 `outputs/轉換問題收集`，包括來源名稱與 SHA-256、模型及規則版本、段落位置、原生標註、一簡多繁字位、待核風險、疑似詞性／分詞問題、自動修正、詞網命中、自訂取代與失敗紀錄。測試與正式轉換分 stage 保存；人工確認的轉換錯誤、原文錯誤、字形偏好與推定補字須另行分類。紀錄包含所處理文字，預設排除於 Git。

## 本機使用

需要 Node.js 20.17 以上、Python 和 [uv](https://docs.astral.sh/uv/)。HanLP 與 LTP 使用各自的 Python 環境。

```sh
npm ci
python3 resources/setup_hanlp.py --python 3.12
python3 resources/setup_ltp.py --python 3.12
npm start
```

開啟 `http://127.0.0.1:8787`。首次安裝會下載依賴與公開模型；LTP 模型在首次使用慢速模式時下載。原始碼不包含模型權重。不同平台的 Python、PyTorch 及原生套件安裝可能需要額外設定。

已安裝模型時，可設定下列環境變數：

| 變數 | 用途 |
| --- | --- |
| `CECC_HANLP_PYTHON` | HanLP 環境的 Python 執行檔 |
| `CECC_HANLP_MODEL` | HanLP 多任務模型目錄 |
| `CECC_LTP_PYTHON` | LTP 環境的 Python 執行檔 |
| `CECC_LTP_MODEL` | LTP 模型目錄或模型 ID |
| `PORT` | 本機 HTTP 埠，預設 8787 |

```js
const { Converter } = require('./app/converter');
async function main() {
const converter = new Converter();
try {
  const result = await converter.convert({
    text: '他有才能，今天才來。',
    direction: 's2t', mode: 'fast', profile: 'modern'
  });
  console.log(result.text);
} finally {
  converter.close();
}
}
main().catch(console.error);
```

直接呼叫亦會分類保存診斷。測試使用 `npm test`；模型整合測試以 `RUN_MODEL_TESTS=1 npm test` 啟用，須先安裝兩個模型。
